# Security and sensitive reports

The Agent Evidence Catalog is a static data and site repository. Security issues
may concern the site, validation scripts, accidental disclosure, impersonation,
malicious evidence links, or sensitive correction and withdrawal material.

## Current private-reporting status

An operational private reporting route has not been verified or enabled for
this repository. The static research preview uses already-public publisher
sources, runs no agents, and keeps intake closed, so this limitation does not
block its release. Public GitHub issues, discussions and pull requests are not
private and must not contain credentials, personal data, proprietary logs,
vulnerability details, exploit steps, embargoed information or unpublished
evidence.

The repository is not currently equipped to receive sensitive reports. The
owner must enable and verify an appropriate private route before accepting
sensitive evidence, confidential withdrawals, embargoed vulnerability detail
or open intake, then update this file with the exact user-facing route. That
future step requires separate explicit authorization and is tracked in
`ROADMAP.md`. No response, triage, remediation or disclosure timeline is
promised.

## Public-safe reports

After publication, ordinary non-sensitive defects may be reported in a public
issue or pull request if the repository enables them. Include the affected path,
expected behavior, actual behavior and a minimal reproduction using synthetic
or already-public data. Do not include secrets or sensitive evidence.

## Maintainer handling

Until a private route exists, the maintainer must not solicit, receive or retain
sensitive material through this repository. If sensitive content appears in a
public report, stop handling it in public, avoid copying it into catalog data
and withhold the affected material. See `GOVERNANCE.md` for correction,
withholding, retention, withdrawal and conflict rules.
