# METR early-2025 productivity study admission audit

Decision: **inapplicable to the exact Cursor 3.14 foreground-Agent record and
excluded from independent tests and findings.**

Source audited: METR's *Measuring the Impact of Early-2025 AI on Experienced
Open-Source Developer Productivity* report and paper.

## Gate results

| Gate | Result | Evidence boundary |
| --- | --- | --- |
| Genuine evaluator independence | Unresolved | METR describes itself as a donation-funded nonprofit and identifies the authors, but the bounded public material does not provide a complete funding or relationship disclosure specific to Anysphere. Independence is not inferred from organization names alone. |
| Exact client applicability | Fail | The study did not pin a Cursor version, package, platform build, digest or source revision. It predates Cursor 3.14. |
| Exact Agent-mode applicability | Fail | Developers were not required to use Cursor; when they did, Agent/Composer and chat use were both present. The result is for an AI-allowed condition, not Cursor foreground Agent. |
| Exact model applicability | Fail | The paper lists multiple models available during the study period but does not bind one model and endpoint revision to each reported Cursor result. |
| Exact configuration applicability | Fail | No effective Cursor mode, permission setting, terminal/MCP authority, privacy state, account flag or backend revision is bound to the outcome. |
| Public artifact availability | Unresolved | The paper and methodology are public, but no public exact-client run receipts establish the missing version/model/configuration linkage required by this catalog record. |

## Catalog consequence

No METR result, evaluator, source, finding, relationship or test is represented
inside the generated Cursor record. The study cannot be rolled forward from
early 2025 to desktop 3.14 or narrowed from general AI-allowed work to one exact
foreground-Agent configuration.
